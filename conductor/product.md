# Initial Concept
Build a specialized Arch Linux ISO where Sway is configured to mimic Zellij's modal workflow, providing a terminal-centric OS experience that boots directly into Kitty. (Updated: Focus on TUI-driven experience with a retro aesthetic and ASCII art/animations).

# Product Definition: Chazos

## 1. Vision Statement
Chazos is a specialized Arch Linux distribution that aims to provide a system-wide TUI (Text-based User Interface) experience with a distinct retro aesthetic. By prioritizing CLI and TUI tools over graphical applications and incorporating ASCII art and animations, Chazos delivers a nostalgic yet powerful computing environment that feels "alive" and focused on terminal-centric productivity.

## 2. Target Audience
- **TUI Enthusiasts:** Users who prefer text-based interfaces and minimal mouse interaction.
- **Retro-Aesthetic Aficionados:** Individuals who appreciate the nostalgic look and feel of early computing.
- **Terminal Power Users:** Developers and system administrators looking for a focused, efficient, and visually interesting OS.

## 3. Core Values
- **TUI-First Interface:** The primary method for system interaction is through TUI and CLI tools.
- **Retro-Modern Aesthetic:** A blend of retro computing visuals (ASCII art, terminal animations) with modern system performance and tools.
- **Interactive Feedback:** Using text-based animations to make the system feel responsive and "alive."
- **Terminal Hub:** Kitty remains the central hub for the OS experience, booting directly into a terminal-centric environment.
- **Nvidia Compatibility:** Seamless integration of modern graphics drivers into the text-based workflow.

## 4. Key Features (MVP)
- **Retro Welcome Experience:** Custom boot animations and ASCII splash screens.
- **TUI Management Tools:** Custom TUI wrappers for system tasks like installation and configuration.
- **Sway-Based Window Management:** Modal window management configured to complement the retro/TUI workflow.
- **Package-First Configuration:** All visual assets and configurations are bundled for consistent delivery.
- **Modern CLI Stack:** Pre-configured with a suite of modern, visually-enhanced CLI tools.

## 5. Success Metrics
- **Aesthetic Consistency:** The retro theme is consistently applied across all system components.
- **Engagement:** The TUI tools are functional and provide clear, animated feedback to the user.
- **Performance:** Despite the visual flair, the system remains fast and responsive.
- **Maintainability:** The custom ASCII and animation assets are easily managed through the established package system.
